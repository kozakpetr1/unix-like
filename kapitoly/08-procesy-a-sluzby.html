Procesy a služby

Každý spuštěný program je proces s vlastním číslem PID. Umíme je vypsat, sledovat, poslat na pozadí a ukončit, a dlouhodobě běžící služby spravujeme přes systemd.

Výpis procesů

$ ps                      # procesy v tomto terminálu
$ ps aux                  # všechny procesy všech uživatelů
$ ps aux --sort=-%mem | head    # největší spotřeba paměti
$ ps -ef --forest         # i s rodiči (PPID)
$ pstree -p               # strom procesů
$ pgrep -a nginx          # PID podle jména
$ pidof sshd

$ ps aux | head -3
USER   PID %CPU %MEM    VSZ   RSS TTY  STAT START  TIME COMMAND
root     1  0.0  0.3 168M  12M ?    Ss   08:01  0:02 /sbin/init
alice 2412  1.2  2.1 812M  84M pts/0 Sl  08:15  0:30 python3 app.py

Stavy procesu (STAT)

Rběží nebo čeká na CPU
Sspí, čeká na událost (nejčastější)
Dnepřerušitelné čekání, typicky na disk
Tzastavený (Ctrl+Z)
Zzombie: skončil, rodič si nevyzvedl výsledek

Sledování v reálném čase

top je vždy k dispozici, htop (apt install htop) je přehlednější a ovládá se šipkami. V top: M řadit podle paměti, P podle CPU, k ukončit proces, q konec.

Popředí a pozadí

příkaz &  → spustí na pozadí
$ sleep 300 &                 # hned vrátí prompt
[1] 3051
$ jobs                        # úlohy tohoto shellu
[1]+  Running    sleep 300 &
$ fg %1                       # zpět do popředí
  … Ctrl+Z …                    pozastavit
$ bg %1                       # pokračovat na pozadí

$ nohup ./zaloha.sh > zaloha.log 2>&1 &
                              # přežije i odhlášení
$ disown %1                   # odpojit úlohu od shellu

$ kill 3051              # SIGTERM
$ kill -9 3051           # SIGKILL, až když TERM nepomůže
$ pkill -f "python3 app.py"   # podle jména/příkazu
$ killall firefox        # všechny procesy daného jména
$ kill -l                # seznam signálů

Priorita

Hodnota nice je od −20 (nejvyšší priorita) do 19 (nejnižší). Zvýšit prioritu může jen root.

$ nice -n 10 tar czf zaloha.tgz /data
$ renice -n 5 -p 3051
$ sudo renice -n -5 -p 3051

Pod kapotou

Informace o každém procesu jsou v adresáři /proc/PID/, např. cat /proc/3051/status.

Služby (systemd)

systemctl status|start|stop|restart|reload|enable|disable služba
$ systemctl status ssh                # běží? od kdy? poslední logy
$ sudo systemctl restart nginx
$ sudo systemctl enable --now nginx   # spouštět po startu + hned spustit
$ sudo systemctl disable bluetooth
$ systemctl list-units --type=service --state=running
$ systemctl --failed                  # co selhalo

$ journalctl -u nginx -f              # logy služby živě
$ journalctl -b -p err                # chyby od posledního startu
