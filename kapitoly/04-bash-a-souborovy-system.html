bash a souborový systém

Bash je výchozí shell v Debianu. Každý příkaz má stejnou stavbu, a jakmile ji umíme číst, umíme číst i nápovědu ke kterémukoli jinému příkazu.

Syntaxe příkazu

příkaz [-přepínače] [argumenty]
$ ls -l -a /etc          # krátké přepínače zvlášť
$ ls -la /etc            # … nebo spojené
$ ls --all --human-readable -l
$ cp -r zdroj/ cil/      # argumenty: odkud, kam

Výzva (prompt)

alice@lab-pc01:~/projekt$       # uživatel@počítač:adresář  $ = běžný uživatel
root@lab-pc01:/etc#             # # = root (opatrně!)

Nápověda a pomůcky

man lsmanuálová stránka (q konec, / hledání)
ls --helpstručný přehled přepínačů
type cdje to vestavěný příkaz, nebo program?
which python3kde leží spustitelný soubor
Tabdoplnění příkazu a cesty

Ctrl+Cpřerušit běžící příkaz
Ctrl+Lvyčistit obrazovku

Cesty

/etc/sshabsolutní — začíná od kořene /
docs/a.txtrelativní — od aktuálního adresáře
~domovský adresář (/home/alice)
.aktuální adresář
..nadřazený adresář
cd -zpět do předchozího adresáře

Zástupné znaky

$ ls *.txt          # libovolný počet znaků
$ ls foto?.jpg      # právě jeden znak
$ ls [abc]*         # začíná a, b nebo c
$ mkdir -p web/{css,js,img}   # rozvinutí závorek

Navigace a prohlížení

$ pwd                        # kde jsem
$ cd /var/log                # přejít
$ ls -lh                     # výpis s čitelnou velikostí
$ ls -lt                     # seřadit podle času změny
$ tree -L 2                  # strom (apt install tree)

$ cat /etc/hostname          # vypsat celý soubor
$ less /var/log/syslog       # listovat (q = konec)
$ head -n 5 /etc/passwd      # prvních 5 řádků
$ tail -n 20 soubor.log      # posledních 20 řádků
$ sudo tail -f /var/log/nginx/access.log   # sledovat živě
$ wc -l /etc/passwd          # počet řádků

Vytváření, kopírování, přesun, mazání

$ mkdir projekt              # nový adresář
$ mkdir -p a/b/c             # včetně rodičů
$ touch poznamky.txt         # prázdný soubor / aktualizace času

$ cp a.txt b.txt             # kopie souboru
$ cp -r projekt/ zaloha/     # kopie adresáře (rekurzivně)
$ cp -i a.txt b.txt          # zeptá se před přepsáním

$ mv a.txt docs/             # přesun
$ mv stary.txt novy.txt      # přejmenování

$ rm b.txt                   # smazat soubor
$ rmdir prazdny/             # smazat prázdný adresář
$ rm -r zaloha/              # smazat adresář s obsahem
$ rm -ri zaloha/             # … s potvrzováním
Pozor: rm nemá koš. Co smažeme, je pryč. Před rm -r s hvězdičkou si nejdřív pusťte ls se stejným vzorem.

Hledání a odkazy

$ find ~ -name "*.pdf"                 # podle jména
$ find /var/log -type f -size +10M     # soubory nad 10 MB
$ find . -mtime -1                     # změněné za 24 h
$ find /tmp -name "*.tmp" -delete     # najít a smazat

$ ln -s /var/www/html web    # symbolický odkaz
$ ls -l web
lrwxrwxrwx 1 alice alice 13 web -> /var/www/html

$ du -sh ~/Stažené           # velikost adresáře
$ df -h                      # volné místo na discích

Uvozovky a proměnné

$ jmeno="Alice"              # bez mezer kolem =
$ echo "Ahoj $jmeno"         # "…" proměnné rozvine
Ahoj Alice
$ echo 'Ahoj $jmeno'         # '…' doslova
Ahoj $jmeno
$ echo "Dnes je $(date +%d.%m.%Y)"   # výstup příkazu
$ echo $HOME $USER $SHELL    # proměnné prostředí
$ echo $PATH                 # kde se hledají příkazy
$ touch "muj soubor.txt"     # mezera v názvu → uvozovky
$ alias ll='ls -lah'         # zkratka (trvale do ~/.bashrc)
$ history | tail -5          # posledních 5 příkazů
