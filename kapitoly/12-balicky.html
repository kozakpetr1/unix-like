Instalace a aktualizace balíčků

Software v Debianu instalujeme z repozitářů pomocí apt. Ten stáhne balíček, ověří jeho podpis, doinstaluje závislosti a později ho umí i aktualizovat.

apt — každodenní příkazy

sudo apt update|upgrade|install|remove|purge|search|show [balíček]
$ sudo apt update                # stáhnout aktuální seznam balíčků
$ apt list --upgradable          # co se dá aktualizovat
$ sudo apt upgrade               # aktualizovat nainstalované
$ sudo apt full-upgrade          # … i když je třeba něco přidat/odebrat

$ apt search "web server"        # hledat
$ apt show nginx                 # popis, verze, závislosti
$ sudo apt install nginx curl    # nainstalovat (i víc najednou)
$ sudo apt install -y htop       # bez dotazu na potvrzení

$ sudo apt remove nginx          # odebrat, konfigurace zůstane
$ sudo apt purge nginx           # odebrat včetně konfigurace
$ sudo apt autoremove            # uklidit nepotřebné závislosti
$ sudo apt clean                 # smazat stažené .deb z cache

Jak apt funguje

repozitář→apt update→seznam balíčků
apt install→stáhne .deb→ověří podpis→dpkg
update ≠ upgrade. update jen zjistí, co je nového. Nainstaluje to až upgrade. Proto se píšou spolu: sudo apt update && sudo apt upgrade.

apt × apt-get

apt je pohodlnější pro člověka (průběh, barvy). Ve skriptech se používá apt-get, protože jeho výstup se nemění.

dpkg — práce s jednotlivými .deb

$ sudo apt install ./program_1.2_amd64.deb   # doporučeno: vyřeší závislosti
$ sudo dpkg -i program_1.2_amd64.deb         # nízkoúrovňově
$ sudo apt -f install                        # dořešit chybějící závislosti

$ dpkg -l | grep nginx           # je nainstalován?
$ dpkg -L nginx                  # jaké soubory balíček obsahuje
$ dpkg -S /usr/sbin/sshd         # ke kterému balíčku soubor patří
$ apt list --installed | wc -l   # počet nainstalovaných
.deb soubory stažené z neznámých webů nejsou ověřené. Instalujte primárně z oficiálních repozitářů.

Repozitáře

Debian 13 „trixie“ používá formát deb822 v souboru /etc/apt/sources.list.d/debian.sources (starší systémy mají /etc/apt/sources.list).

Types: deb
URIs: https://deb.debian.org/debian
Suites: trixie trixie-updates
Components: main contrib non-free non-free-firmware
Signed-By: /usr/share/keyrings/debian-archive-keyring.gpg

Types: deb
URIs: https://security.debian.org/debian-security
Suites: trixie-security
Components: main contrib non-free non-free-firmware
mainsvobodný software, plně podporovaný
contribsvobodný, ale závisí na nesvobodném
non-free(-firmware)nesvobodný software a firmware (Wi-Fi, GPU)

Automatické bezpečnostní aktualizace

$ sudo apt install unattended-upgrades
$ sudo dpkg-reconfigure -plow unattended-upgrades
$ systemctl list-timers apt-daily*        # kdy poběží
$ less /var/log/unattended-upgrades/unattended-upgrades.log

Na serverech je to rozumný základ: bezpečnostní opravy se nainstalují samy, větší změny dělá správce ručně.
