Správa uživatelů a skupin

Účty a skupiny jsou obyčejné řádky v textových souborech. Nástroje níže je upravují bezpečně a hlídají, aby soubory zůstaly konzistentní.

Kde jsou uživatelé uloženi

$ grep alice /etc/passwd
alice:x:1001:1001:Alice Nováková,,,:/home/alice:/bin/bash
  │    │  │    │        │               │           └ shell
  │    │  │    │        │               └ domovský adresář
  │    │  │    │        └ celé jméno (GECOS)
  │    │  │    └ GID primární skupiny
  │    │  └ UID
  │    └ heslo je jinde (x → /etc/shadow)
  └ login
/etc/passwdúčty, čitelné pro všechny
/etc/shadowhashe hesel a jejich platnost, jen pro root
/etc/groupskupiny a jejich členové
/etc/skel/šablona obsahu nového domovského adresáře

UID 0 = root, 1–999 = systémové účty služeb, od 1000 = běžní uživatelé.

Kdo jsem a kdo je přihlášen

$ whoami
$ id alice
uid=1001(alice) gid=1001(alice) skupiny=1001(alice),27(sudo)
$ groups
$ who            # přihlášení uživatelé
$ w              # … a co dělají
$ last -n 5      # poslední přihlášení
$ getent passwd alice

Vytvoření uživatele

adduser — interaktivní, doporučeno v Debianu

$ sudo adduser jan
Adding user `jan' ...
Creating home directory `/home/jan' ...
New password: ********
Full Name []: Jan Novák

useradd — nízkoúrovňový, pro skripty

$ sudo useradd -m -s /bin/bash -c "Jan Novák" -G users jan
$ sudo passwd jan
# -m domovský adresář, -s shell, -c komentář, -G další skupiny
Bez -m a -s vytvoří useradd účet bez domovského adresáře a se shellem /bin/sh.

Úprava účtu — usermod

usermod [volby] uživatel
$ sudo usermod -aG docker jan         # přidat do skupiny (-a = append!)
$ sudo usermod -s /bin/zsh jan        # změnit shell
$ sudo usermod -c "Jan Novák, 3.B" jan
$ sudo usermod -l jnovak jan          # přejmenovat login
$ sudo usermod -d /home/jnovak -m jnovak   # přesunout domov
$ sudo usermod -e 2027-06-30 jnovak   # účet vyprší
$ sudo usermod -L jnovak              # zamknout
$ sudo usermod -U jnovak              # odemknout
usermod -G skupina bez -a uživatele odebere ze všech ostatních doplňkových skupin, třeba i ze sudo.

Hesla a jejich platnost

$ passwd                     # změnit vlastní heslo
$ sudo passwd jan            # nastavit heslo jinému
$ sudo passwd -e jan         # vynutit změnu při příštím přihlášení
$ sudo passwd -l jan         # zamknout heslo
$ sudo passwd -S jan         # stav hesla

$ sudo chage -l jan          # přehled platnosti
$ sudo chage -M 90 -W 7 jan  # max. 90 dní, varovat 7 dní předem

Skupiny a smazání účtu

$ sudo addgroup ucitele               # nebo groupadd
$ sudo adduser jan ucitele            # přidat člena (Debian)
$ sudo gpasswd -a jan ucitele         # přidat člena
$ sudo gpasswd -d jan ucitele         # odebrat člena
$ sudo groupmod -n vyuka ucitele      # přejmenovat skupinu
$ sudo delgroup vyuka                 # smazat skupinu
$ getent group sudo                   # členové skupiny

$ sudo deluser jan                    # smazat účet, data zůstanou
$ sudo deluser --remove-home jan      # i s domovským adresářem
$ sudo userdel -r jan                 # totéž nízkoúrovňově

Změna členství ve skupinách se projeví po novém přihlášení (nebo newgrp skupina).
