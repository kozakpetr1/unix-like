Kapitola 13 · Skriptování

Skriptování v bashi

Skript je textový soubor s příkazy, které by jinak člověk psal ručně jeden po druhém. Stačí ho jednou napsat a pak spouštět znovu a znovu. Ukázky jdou od prvního „Ahoj, světe“ přes vstupy, výstupy, podmínky a cykly až po proměnné prostředí a regulární výrazy.

Jak vytvořit skript

  1. Otevřete editor s novým souborem: nano ahoj.sh (kapitola 5). Přípona .sh není povinná, ale ukazuje, co je soubor zač.
  2. Na první řádek napište shebang #!/bin/bash. Říká systému, kterým programem se má skript vykonat.
  3. Pod něj napište příkazy, každý na vlastní řádek. Řádky začínající # jsou komentáře.
  4. Uložte (Ctrl+O) a zavřete editor (Ctrl+X).
  5. Přidejte právo ke spuštění chmod +x ahoj.sh a spusťte ./ahoj.sh.
#!/bin/bash
# Můj první skript
echo "Ahoj, světe!"
echo "Dnes je $(date +%d.%m.%Y)."

Oprávnění ke spuštění

Nový soubor dostane práva rw-r--r--, tedy čtení a zápis, ale ne spuštění. Bash ho proto odmítne. Právo x přidá chmod (kapitola 11).

$ ls -l ahoj.sh
-rw-r--r-- 1 petr petr 88 Nov  3 08:28 ahoj.sh
$ ./ahoj.sh
bash: ./ahoj.sh: Permission denied
$ chmod +x ahoj.sh
$ ls -l ahoj.sh
-rwxr-xr-x 1 petr petr 88 Nov  3 08:28 ahoj.sh
$ ./ahoj.sh
Ahoj, světe!
Dnes je 03.11.2026.

První kroky

shebang, komentáře, proměnné a substituce

01Ahoj, světe

Nejmenší možný skript. První řádek #!/bin/bash (shebang) říká systému, kterým interpretem soubor spustit. Vše za # je komentář.

#!/bin/bash
# Můj první skript
echo "Ahoj, světe!"
echo "Dnes je $(date +%d.%m.%Y)."
$ ./ahoj.sh
Ahoj, světe!
Dnes je 03.11.2026.

02Proměnné

Proměnnou přiřadíme bez mezer kolem = a čteme ji přes $. Hodnotu dávejte do uvozovek; ve dvojitých se proměnné rozbalí, v jednoduchých ne.

#!/bin/bash
jmeno="Petr"
predmet="Operační systémy"
pocet=3

echo "Uživatel: $jmeno"
echo "Předmět:  ${predmet}"
echo 'Doslova:  $jmeno'          # jednoduché uvozovky nerozbalují
echo "Soubor:   ${jmeno}_${pocet}.txt"   # složené závorky oddělí název
$ ./promenne.sh
Uživatel: Petr
Předmět:  Operační systémy
Doslova:  $jmeno
Soubor:   Petr_3.txt

jmeno = "Petr" s mezerami je chyba: bash by hledal příkaz jmeno.

03Výstup příkazu a aritmetika

$(prikaz) vloží výstup příkazu do textu nebo proměnné. $(( )) počítá s celými čísly.

#!/bin/bash
uzivatel=$(whoami)
soubory=$(ls /etc | wc -l)
echo "Přihlášen je $uzivatel, v /etc je $soubory položek."

a=17
b=5
echo "Součet:  $((a + b))"
echo "Podíl:   $((a / b)) zbytek $((a % b))"
echo "Mocnina: $((2 ** 10))"
((a++))                          # zvětšení o 1
echo "a je teď $a"
$ ./substituce.sh

Vstupy a výstupy

argumenty, read, printf, přesměrování a návratové kódy

04Argumenty z příkazové řádky

Hodnoty zadané za názvem skriptu jsou v $1, $2… Jejich počet je $#, všechny najednou "$@".

$0název skriptu$#počet argumentů
$1 … $9jednotlivé argumenty"$@"všechny, každý zvlášť
#!/bin/bash
echo "Skript:      $0"
echo "Počet:       $#"
echo "První:       $1"
echo "Druhý:       $2"
for arg in "$@"; do
    echo " - $arg"
done
$ ./argumenty.sh jablko "zelená hruška" švestka

Počet:       3
První:       jablko
Druhý:       zelená hruška

 - zelená hruška
 - švestka

05Čtení vstupu: read

read počká, až uživatel napíše řádek a stiskne Enter. Volba -p vypíše výzvu, -s skryje psaný text (hesla).

#!/bin/bash
read -p "Jak se jmenuješ? " jmeno
read -p "Kolik ti je let? " vek
read -s -p "Tajné heslo: " heslo
echo                             # nový řádek po skrytém vstupu

echo "Ahoj $jmeno, za 10 let ti bude $((vek + 10))."
echo "Heslo má ${#heslo} znaků."
$ ./dotaz.sh
Jak se jmenuješ? Jana
Kolik ti je let? 19
Tajné heslo: 
Ahoj Jana, za 10 let ti bude 29.
Heslo má 8 znaků.

06Formátovaný výstup: printf

echo stačí na jednoduchý text. Pro zarovnané sloupce je lepší printf: %s text, %d celé číslo, %-10s zarovnání vlevo na 10 znaků.

#!/bin/bash
printf "%-12s %8s\n" "Cesta" "Soubory"
printf "%-12s %8s\n" "-----" "-------"
for d in /etc /bin /usr /var; do
    printf "%-12s %8d\n" "$d" "$(ls "$d" | wc -l)"
done
printf "Hotovo v %s\n" "$(date +%H:%M)"
$ ./tabulka.sh
Cesta         Soubory
-----         -------
/etc              166
/bin             1454
/usr               10
/var               11
Hotovo v 08:28

Čísla se na každém počítači liší. Pozor: printf měří šířku v bajtech a písmena s diakritikou mají 2 bajty, proto jsou v zarovnaných sloupcích nadpisy bez háčků a čárek.

07Zápis do souboru, chyby a here-doc

Uvnitř skriptu fungují stejná přesměrování jako v terminálu (kapitola 6). Chybové hlášky patří na stderr: >&2. Here-doc <<EOF zapíše víc řádků najednou.

#!/bin/bash
log="zaznam.log"

echo "$(date +%T) start" >> "$log"       # připojí řádek
echo "Toto je chybová hláška" >&2      # jde na stderr

cat > info.txt <<EOF
Počítač: $(hostname)
Uživatel: $USER
Jádro: $(uname -r)
EOF

echo "Vytvořen soubor info.txt ($(wc -l < info.txt) řádky)"
$ ./zapis.sh 2>/dev/null
Vytvořen soubor info.txt (3 řádky)
$ cat zaznam.log
08:28:05 start

08Návratový kód a exit

Každý příkaz končí kódem: 0 = úspěch, cokoli jiného = chyba. Poslední kód je v $?. Skript ho vrací příkazem exit, takže jde řetězit pomocí && a ||.

#!/bin/bash
if [ $# -ne 1 ]; then
    echo "Použití: $0 UŽIVATEL" >&2
    exit 2
fi

grep -q "^$1:" /etc/passwd
if [ $? -eq 0 ]; then
    echo "Účet $1 existuje."
    exit 0
else
    echo "Účet $1 neexistuje."
    exit 1
fi
$ ./kontrola.sh root
Účet root existuje.
$ ./kontrola.sh nikdo; echo "kód: $?"
Účet nikdo neexistuje.
kód: 1
$ ./kontrola.sh; echo "kód: $?"
Použití: ./kontrola.sh UŽIVATEL
kód: 2

09Podmínka if a testy souborů

[[ … ]] je test; mezery za [[ a před ]] jsou povinné. Testy souborů:

-eexistuje-fběžný soubor-dadresář
-rlze číst-wlze zapisovat-xlze spustit
-snení prázdný-z "$x"prázdný řetězec!negace
#!/bin/bash
cesta="$1"

if [[ -z "$cesta" ]]; then
    echo "Zadej cestu."
elif [[ -d "$cesta" ]]; then
    echo "$cesta je adresář."
elif [[ -f "$cesta" ]]; then
    echo "$cesta je soubor, velikost $(stat -c %s "$cesta") B."
    [[ -x "$cesta" ]] && echo "Je spustitelný."
else
    echo "$cesta neexistuje."
fi
$ ./soubor.sh /etc
/etc je adresář.
$ ./soubor.sh soubor.sh
soubor.sh je soubor, velikost 316 B.
Je spustitelný.
$ ./soubor.sh /nic
/nic neexistuje.

10Porovnávání čísel

Čísla porovnáváme v (( )) běžnými znaménky, nebo v [[ ]] zkratkami -eq -ne -lt -le -gt -ge. Znak < v [[ ]] porovnává text, ne čísla.

#!/bin/bash
read -p "Počet bodů (0–100): " body

if (( body >= 90 )); then
    znamka=1
elif (( body >= 75 )); then
    znamka=2
elif (( body >= 60 )); then
    znamka=3
elif [[ $body -ge 45 ]]; then
    znamka=4
else
    znamka=5
fi
echo "Známka: $znamka"
$ ./znamka.sh
Počet bodů (0–100): 78
Známka: 2

11Výběr z možností: case

case porovná hodnotu se vzory (lze použít *, ?, |). Každá větev končí ;;, celý blok esac. Hodí se na zpracování voleb skriptu.

#!/bin/bash
case "$1" in
    start)
        echo "Spouštím službu…" ;;
    stop|halt)
        echo "Zastavuji službu…" ;;
    status)
        echo "Služba běží." ;;
    *.txt)
        echo "Zadal jsi textový soubor $1." ;;
    *)
        echo "Použití: $0 {start|stop|status}"
        exit 1 ;;
esac
$ ./sluzba.sh start
Spouštím službu…
$ ./sluzba.sh halt
Zastavuji službu…
$ ./sluzba.sh poznamky.txt
Zadal jsi textový soubor poznamky.txt.
$ ./sluzba.sh restart
Použití: ./sluzba.sh {start|stop|status}

12Cyklus for

for projde seznam hodnot: vyjmenovaný, rozsah {1..5}, soubory podle masky, nebo výstup příkazu. Existuje i zápis podobný jazyku C.

#!/bin/bash
for os in Debian Fedora Arch; do
    echo "Distribuce: $os"
done

for i in {1..5}; do
    echo -n "$i "
done
echo

for ((i = 10; i > 0; i -= 3)); do
    echo -n "$i "
done
echo

for f in /etc/host*; do
    echo "Soubor: $f"
done

13Cyklus while a čtení souboru

while opakuje, dokud je podmínka pravdivá. Spojení while read čte soubor řádek po řádku; IFS=: nastaví oddělovač, takže read rozdělí řádek do proměnných.

#!/bin/bash
# Vypíše uživatele, kteří se mohou přihlásit (shell bash)
pocet=0
while IFS=: read -r jmeno x uid gid popis domov shell; do
    if [[ "$shell" == "/bin/bash" ]]; then
        echo "$jmeno (UID $uid) → $domov"
        ((pocet++))
    fi
done < /etc/passwd
echo "Celkem: $pocet"
$ ./ucty.sh
root (UID 0) → /root
petr (UID 1000) → /home/petr
Celkem: 2

Výsledek závisí na účtech v systému.

14Hra: while, break a continue

$RANDOM dává náhodné číslo 0–32767. while true běží donekonečna, break cyklus ukončí a continue přeskočí na další kolo.

#!/bin/bash
cislo=$((RANDOM % 20 + 1))
pokusy=0
echo "Myslím si číslo 1–20."

while true; do
    read -p "Tvůj tip: " tip
    if ! [[ "$tip" =~ ^[0-9]+$ ]]; then
        echo "To není číslo."
        continue
    fi
    ((pokusy++))
    if (( tip < cislo )); then echo "Víc."
    elif (( tip > cislo )); then echo "Míň."
    else
        echo "Správně! Počet pokusů: $pokusy"
        break
    fi
done

15Funkce

Funkce pojmenuje opakovaný kus kódu. Argumenty dostává stejně jako skript ($1, $#), local omezí proměnnou na funkci. Výsledek se vrací výpisem (echo), return vrací jen kód 0–255.

#!/bin/bash
nadpis() {
    echo "=== $1 ==="
}

obsah_kruhu() {
    local r=$1
    echo $((314 * r * r / 100))
}

je_sude() {
    (( $1 % 2 == 0 ))            # kód 0 = pravda
}

nadpis "Výpočty"
echo "Kruh r=10: $(obsah_kruhu 10)"
for n in 3 8; do
    if je_sude "$n"; then echo "$n je sudé"; else echo "$n je liché"; fi
done
$ ./funkce.sh
=== Výpočty ===
Kruh r=10: 314
3 je liché
8 je sudé

16Pole

Pole uchová víc hodnot pod jedním jménem. ${pole[@]} jsou všechny prvky, ${#pole[@]} jejich počet, += přidá prvek na konec.

#!/bin/bash
ovoce=("jablko" "hruška" "švestka")
ovoce+=("meruňka")

echo "První:  ${ovoce[0]}"
echo "Počet:  ${#ovoce[@]}"
echo "Všechny: ${ovoce[*]}"

for i in "${!ovoce[@]}"; do
    echo "$i: ${ovoce[$i]}"
done

soubory=(/etc/*.conf)          # pole ze jmen souborů
echo "V /etc je ${#soubory[@]} souborů .conf"
$ ./pole.sh

Počet:  4

17Proměnné prostředí

Shell předává každému programu sadu proměnných prostředí. Vypíšete je příkazem env nebo printenv. Zápis ${X:-výchozí} použije náhradní hodnotu, když X není nastavena.

#!/bin/bash

echo "PID skriptu: $$"

18export: předání proměnné dalším programům

Běžná proměnná platí jen v aktuálním shellu. Až po export ji uvidí i programy a skripty, které z něj spustíte. Opačným směrem to nefunguje: skript nezmění proměnné shellu, který ho spustil.

#!/bin/bash
lokalni="jen tady"
export SDILENA="vidí i potomci"

bash -c 'echo "Potomek vidí: lokalni=[$lokalni] SDILENA=[$SDILENA]"'
$ ./export.sh

$ source nastaveni.sh   # nebo zkráceně: . nastaveni.sh

19Trvalé nastavení v ~/.bashrc

Proměnné nastavené v terminálu zmizí po jeho zavření. Natrvalo je zapíšete do ~/.bashrc, který bash načte při každém otevření terminálu. Tak si také přidáte vlastní adresář se skripty do PATH.

# ~/.bashrc (konec souboru)
export EDITOR=nano
export PATH="$HOME/bin:$PATH"     # moje skripty spustím odkudkoli
alias ll='ls -lah'
$ mkdir -p ~/bin && mv ahoj.sh ~/bin/ahoj
$ source ~/.bashrc
$ ahoj

Regulární výrazy ve skriptech

kontrola vstupu, vytažení údajů a zpracování logu

20Kontrola vstupu: operátor =~

V [[ text =~ vzor ]] je vpravo rozšířený regulární výraz (kapitola 7). Vzor je bezpečnější uložit do proměnné a psát bez uvozovek, jinak by se bral doslova.

#!/bin/bash
re_email='^[a-z0-9._-]+@[a-z0-9.-]+\.[a-z]{2,}$'
re_psc='^[0-9]{3} ?[0-9]{2}$'

for vstup in "jan.novak@skola.cz" "spatny@email" "407 47" "4074"; do
    if [[ $vstup =~ $re_email ]]; then
        echo "$vstup → e-mail"
    elif [[ $vstup =~ $re_psc ]]; then
        echo "$vstup → PSČ"
    else
        echo "$vstup → neznámý formát"
    fi
done
$ ./over.sh
jan.novak@skola.cz → e-mail
spatny@email → neznámý formát
407 47 → PSČ
4074 → neznámý formát

21Vytažení částí: BASH_REMATCH

Části vzoru v závorkách ( ) se po shodě uloží do pole BASH_REMATCH: [0] je celá shoda, [1] první závorka atd.

#!/bin/bash
re='^([0-9]{4})-([0-9]{2})-([0-9]{2})$'

if [[ $1 =~ $re ]]; then
    rok=${BASH_REMATCH[1]}
    mesic=${BASH_REMATCH[2]}
    den=${BASH_REMATCH[3]}
    echo "Česky: $((10#$den)). $((10#$mesic)). $rok"
else
    echo "Zadej datum ve tvaru RRRR-MM-DD" >&2
    exit 1
fi
$ ./datum.sh 2026-11-03
Česky: 3. 11. 2026
$ ./datum.sh 3.11.2026
Zadej datum ve tvaru RRRR-MM-DD

22Analýza logu: grep, sed a awk

Skript vezme log webového serveru a vypíše přehled: kolik bylo požadavků, které IP adresy se ptaly nejčastěji a které stránky skončily chybou 404. Kombinuje grep -E, sed -E a roury.

#!/bin/bash
log="${1:-access.log}"
[[ -r "$log" ]] || { echo "Nelze číst $log" >&2; exit 1; }

echo "Požadavků celkem: $(wc -l < "$log")"

echo "Nejčastější IP adresy:"
grep -oE '^([0-9]{1,3}\.){3}[0-9]{1,3}' "$log" | sort | uniq -c | sort -rn | head -3

echo "Chyby 404:"
grep -E '" 404 ' "$log" | sed -E 's/.*"GET ([^ ]+) .*/  \1/' | sort -u

echo "Požadavky podle hodiny:"
sed -E 's/.*:([0-9]{2}):[0-9]{2}:[0-9]{2} .*/\1/' "$log" | sort | uniq -c

23Shrnutí: zálohovací skript

Všechno dohromady: argument s výchozí hodnotou, kontrola vstupu, funkce, proměnná prostředí, podmínky, regulární výraz a návratové kódy. Zabalí zadaný adresář do archivu s datem a ponechá jen 3 nejnovější zálohy.

#!/bin/bash
set -euo pipefail                # při chybě skript hned skončí

zdroj="${1:-$HOME/dokumenty}"
cil="${ZALOHY:-$HOME/zalohy}"
ponechat=3

chyba() { echo "CHYBA: $*" >&2; exit 1; }

[[ -d "$zdroj" ]] || chyba "adresář $zdroj neexistuje"
mkdir -p "$cil"

nazev="$(basename "$zdroj")_$(date +%Y-%m-%d_%H%M%S).tar.gz"
tar -czf "$cil/$nazev" -C "$(dirname "$zdroj")" "$(basename "$zdroj")"
echo "Vytvořeno: $nazev ($(du -h "$cil/$nazev" | cut -f1))"

# smazat starší zálohy, ponechat poslední $ponechat
ls -1t "$cil" | grep -E '\.tar\.gz$' | tail -n +$((ponechat + 1)) | while read -r stary; do
    rm -- "$cil/$stary"
    echo "Smazáno:   $stary"
done
$ ./zaloha.sh ~/projekt
Vytvořeno: projekt_2026-11-03_082808.tar.gz (4.0K)
Smazáno:   projekt_2026-10-30_180000.tar.gz
$ ls ~/zalohy
projekt_2026-10-31_180000.tar.gz  projekt_2026-11-03_082808.tar.gz
projekt_2026-11-01_180000.tar.gz

Dobré zvyky

  • Vždy začínejte shebangem #!/bin/bash.
  • Proměnné dávejte do uvozovek: "$soubor". Jinak se název s mezerou rozpadne na dva argumenty.
  • U důležitých skriptů použijte set -euo pipefail: skript skončí při první chybě nebo nenastavené proměnné.
  • Chyby vypisujte na stderr (>&2) a končete nenulovým exit.
  • Kontrolujte vstupy a vypište nápovědu, když chybí argumenty.
  • Pište komentáře a srozumitelné názvy proměnných.
Dál: v kapitole 14 necháte skripty spouštět automaticky v naplánovaný čas pomocí cronu.
